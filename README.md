**QueryEase — AI-Powered SQL Query System** · 2025
Translates plain-English questions into optimised SQL through an LLM, on a dual-service Express.js + FastAPI architecture. A schema-aware engine maps user intent onto actual database structures to cut hallucinations, and EXPLAIN-based validation with self-correcting retry logic pushes query accuracy to 99%.
`Node.js` `FastAPI` `Python` `SQL` `REST APIs` → [Repo](https://github.com/rr-code/queryease)

**SpendGood — Expense Tracker Web App** · 2025
A zero-backend expense tracker built as a React 18 SPA, with state persisted client-side via redux-persist so it works fully offline. Custom `useDebounce` hook powers real-time search alongside a multi-filter system (category, date range, sort) and memoised selectors. Recharts drives the donut and bar dashboards; Lighthouse score 90+.
`React 18` `TypeScript` `Redux Toolkit` `Recharts` `Zod` `Tailwind` → [Repo](https://github.com/rr-code/spendgood)
